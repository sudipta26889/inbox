# MCP Server Setup

The Inbox MCP (Model Context Protocol) Server allows AI assistants like Claude Desktop, VS Code Copilot, and other MCP clients to securely access your email account through OAuth 2.1 authentication.

## What is MCP?

Model Context Protocol (MCP) is an open protocol that enables AI assistants to securely connect to external data sources and tools. With Inbox's MCP server, you can:

- Search your emails using natural language
- Get email details and content
- Send emails via AI assistant
- Check calendar availability
- View email statistics
- Manage automation rules

All through natural conversation with your AI assistant!

## Prerequisites

- An Inbox account with Gmail or Outlook connected
- Claude Desktop, VS Code, or another MCP-compatible client
- Inbox MCP Server enabled (see Configuration below)

## Configuration

### For Self-Hosted Installations

Add to your `.env` file:

```bash
NEXT_PUBLIC_MCP_SERVER_ENABLED=true
```

Then restart your Inbox server and run the database migration:

```bash
cd apps/web
npx prisma migrate deploy
pnpm dev
```

### For inbox.sudiptadhara.in Users

The MCP server is already enabled! You can connect directly.

## Connecting Claude Desktop

### Step 1: Open Claude Desktop Configuration

On macOS:
```bash
code ~/Library/Application\ Support/Claude/claude_desktop_config.json
```

On Windows:
```bash
code %APPDATA%\Claude\claude_desktop_config.json
```

On Linux:
```bash
code ~/.config/Claude/claude_desktop_config.json
```

### Step 2: Add Inbox MCP Server

Add the following to your configuration:

```json
{
  "mcpServers": {
    "inbox": {
      "type": "http",
      "url": "https://inbox.sudiptadhara.in/mcp-server"
    }
  }
}
```

For self-hosted installations, replace the URL with your own:

```json
{
  "mcpServers": {
    "inbox": {
      "type": "http",
      "url": "https://your-domain.com/mcp-server"
    }
  }
}
```

### Step 3: Restart Claude Desktop

Quit and restart Claude Desktop. It will automatically:

1. Discover the OAuth endpoints
2. Register as a client
3. Open your browser for authorization
4. Prompt you to log in (if needed)
5. Show a consent screen

### Step 4: Authorize Access

In the browser window:

1. Log in to your Inbox account (if not already logged in)
2. Review the requested permissions
3. Click **"Authorize"**

Claude Desktop will now have access to your Inbox account!

## Permissions (OAuth Scopes)

When you authorize Claude Desktop, you grant these permissions:

| Scope | Description |
|-------|-------------|
| `email:read` | Read your emails and search inbox |
| `email:write` | Send emails on your behalf |
| `calendar:read` | View calendar events and availability |
| `stats:read` | Access email analytics |
| `rules:read` | View automation rules |
| `rules:write` | Create and modify automation rules |

You can revoke access at any time in your Inbox Settings.

## Security

### How OAuth 2.1 Works

1. **No passwords shared** - Claude Desktop never sees your Inbox password
2. **PKCE protected** - Prevents authorization code interception attacks
3. **Short-lived tokens** - Access tokens expire after 1 hour
4. **Refresh tokens** - Long-lived tokens for seamless renewal
5. **Scope-based** - Fine-grained permissions control
6. **Revocable** - You can revoke access anytime

### What Claude Can Access

Claude Desktop can only:
- Access data within the granted scopes
- Perform actions you've explicitly authorized
- Access YOUR email account (not other users)

Claude Desktop cannot:
- Access your Inbox password
- Access other users' emails
- Modify your account settings
- Access data beyond granted scopes

### Revoking Access

To revoke Claude Desktop's access:

1. Go to Inbox Settings
2. Navigate to "Connected Apps" or "API Keys"
3. Find "Claude Desktop" in the list
4. Click "Revoke Access"

## Troubleshooting

### "MCP Server is not enabled"

**Solution:** Set `NEXT_PUBLIC_MCP_SERVER_ENABLED=true` in your `.env` file and restart the server.

### "No email account connected"

**Solution:** Connect your Gmail or Outlook account first at [https://inbox.sudiptadhara.in/settings](https://inbox.sudiptadhara.in/settings)

### "Authorization failed"

**Solutions:**
- Make sure you're logged in to Inbox
- Try clearing your browser cache
- Check that you have an email account connected
- Verify the MCP server URL is correct

### "Invalid or expired access token"

**Solution:** This usually resolves automatically through token refresh. If not, revoke access and re-authorize.

### "Insufficient permissions"

**Solution:** The requested action requires a scope you haven't granted. Re-authorize and grant the necessary permissions.

### Custom MCP Clients

Use the MCP SDK:

```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";

const client = new Client({
  name: "my-app",
  version: "1.0.0",
});

// Connect to Inbox MCP server
await client.connect({
  url: "https://inbox.sudiptadhara.in/mcp-server",
  oauth: {
    discoveryUrl: "https://inbox.sudiptadhara.in/.well-known/oauth-protected-resource",
  },
});

// List available tools
const tools = await client.listTools();

// Call a tool
const result = await client.callTool({
  name: "search_emails",
  arguments: {
    query: "subject:invoice",
    maxResults: 10,
  },
});
```

## API Reference

### Discovery Endpoints

- **Protected Resource Metadata (RFC 9728)**
  `GET /.well-known/oauth-protected-resource`

- **Authorization Server Metadata (RFC 8414)**
  `GET /.well-known/oauth-authorization-server`

### OAuth Endpoints

- **Client Registration (RFC 7591)**
  `POST /mcp-server/register`

- **Authorization**
  `GET /mcp-server/authorize`

- **Token Exchange**
  `POST /mcp-server/token`

### MCP Protocol

- **Server Info**
  `GET /mcp-server`

- **MCP Requests**
  `POST /mcp-server`
